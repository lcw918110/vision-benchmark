## 五、 统计口径说明

1. **配对规则**：图片与其同名 `.txt` 按文件名主干（stem）配对；同一目录下多格式同名图按各自 stem 归一。
2. **纯背景图**：存在标注文件但文件为空（0 行有效框），计为空标注 / 纯背景样本。
3. **缺标注图片**：图片存在但无同名 `.txt`，此类样本无法直接用于监督训练。
4. **孤立标注**：`.txt` 存在但无同名图片，多为历史清理残留。
5. **异常标注行**：列数不等于 5（HBB）或 9（OBB），或类别 ID / 坐标无法解析的行。
6. **目标尺度**：沿用 [`docs/dataset-standard-report.md`](./dataset-standard-report.md) 的口径，以归一化宽高乘 `640` 折算像素面积后分档，便于与 5,700 张标准测试集报告横向对照；该口径对非方形输入（如 `640×1152`）为近似值。
7. **OBB 外接框**：旋转框取 4 顶点坐标的轴对齐外接矩形计算宽高。
8. **磁盘占用**：按文件 `st_size` 累加，不含文件系统块对齐开销，故略小于 `du` 结果。
